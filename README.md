# RefundPilot Multi-Agent 退款争议仲裁台

一个面向电商退款、赔付和责任判断场景的多 Agent 工作流演示项目。

## 项目定位

这个项目不是泛化的对话摘要工具，而是一个聚焦退款争议仲裁场景的 Agent 原型。

它把原始争议对话拆给多个分工明确的 Agent：

- 受理 Agent：识别争议主题、买家情绪和主诉焦点
- 证据 Agent：抽取签收凭证、仓库节点、退款路径等关键证据
- 规则 Agent：核对页面承诺、活动规则与人工说明是否一致
- 仲裁 Agent：输出责任线索、升级建议和处置方向
- 回复 Agent：生成带时限承诺的推荐回复
- 复盘 Agent：沉淀完整仲裁报告和优化建议

## 解决的核心痛点

- 退款超时、签收争议、延迟发货等场景需要人工反复阅读长对话
- 页面承诺、仓库状态、物流回传和人工口径容易前后冲突
- 一线处理常常只停留在“帮您核实”，缺少时限承诺和闭环动作

## 当前能力

- 支持直接粘贴买家与商家对话
- 内置退款到账延迟、物流签收争议、延迟发货赔付三个演示场景
- 支持标准仲裁、严格仲裁、教练模式三种运行方式
- 自动输出履约得分、买家情绪、争议等级
- 展示 Agent Trace、仲裁链路和核心证据片段
- 自动生成处置建议、升级建议、推荐回复和仲裁报告

## 技术形态

- 纯前端静态页面
- 无需后端服务
- 适合部署到 GitHub Pages、Netlify 或 Vercel
