# ServicePilot Multi-Agent 客服工单分诊台

一个面向中文客服、售后和运营团队的多 Agent 对话质检与复盘演示项目。

## 项目定位

这个项目不是单纯的页面分析器，而是一个面向客服场景的 Agent 工作流原型。

它把原始客服对话交给多个角色分工明确的 Agent：

- 分诊 Agent：识别问题类型、用户情绪和主诉焦点
- 规则 Agent：检查规则冲突、SLA 时限和承诺缺口
- 回复 Agent：生成更稳的客服回复与闭环话术
- 升级 Agent：判断是否需要主管介入、补偿或工单升级
- 复盘 Agent：输出结构化复盘结论和可复制报告

## 解决的核心痛点

- 高风险会话难以及时识别，投诉和升级信号容易漏掉
- 坐席口径不一致，规则冲突会放大用户不满
- 主管复盘依赖人工阅读和总结，质检效率低且不稳定

## 当前能力

- 支持直接粘贴客服与客户对话
- 内置退款争议、物流催单、会员投诉三个演示场景
- 支持标准质检、严格质检、教练模式
- 自动输出服务得分、客户情绪、风险等级
- 展示 Agent Trace，保留工作流运行痕迹
- 自动生成推荐回复、升级建议和复盘报告

## 技术形态

- 纯前端静态页面
- 无需后端服务
- 适合部署到 GitHub Pages、Netlify 或 Vercel

## 演示建议

1. 打开 `index.html`
2. 选择一个演示场景
3. 点击“加载示例”
4. 点击“运行 Agent 工作流”
5. 查看 Agent 协作链路、风险节点、推荐回复和复盘报告

## 为什么适合申请材料

相比泛化摘要工具，这个项目更符合“Agent / AI 驱动成果”的描述方式：有明确痛点、有多 Agent 分工、有运行痕迹，也更容易配合截图、在线演示地址和 GitHub 链接一起作为证明材料。
