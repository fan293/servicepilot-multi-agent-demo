Customer Support Multi-Agent Workflow

ServicePilot Multi-Agent 客服工单分诊台

面向售后客服、在线支持和运营质检的多 Agent 原型。它把原始会话交给分诊 Agent、规则 Agent、回复 Agent、升级 Agent 和复盘 Agent，自动完成问题分类、风险判定、标准回复生成和复盘报告输出。

Multi-Agent Demo 适合在线演示、截图和项目申请材料

解决的核心痛点

减少客服主管手动看记录、判断风险、改写话术和写复盘的重复劳动。

  • 高风险会话难以及时识别，投诉和升级信号容易漏掉
  • 不同坐席口径不一致，规则冲突会直接放大用户不满
  • 主管复盘依赖人工阅读和总结，质检效率低且不稳定

Agent 协作链路

一段客服对话会依次经过 5 个 Agent，形成有痕迹的分析链路。

01
分诊 Agent

识别问题类型、用户情绪和主诉焦点

02
规则 Agent

检查规则冲突、SLA 时限和承诺缺口

03
回复 Agent

生成更稳的客服回复与闭环话术

04
升级 Agent

判断是否需要主管介入、补偿或工单升级

05
复盘 Agent

输出结构化复盘结论和可复制报告
